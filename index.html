Privacy Policy

Effective Date: November 1, 2026 · applies to version 1.9.0

SmartTranslate AI Assistant+ ("the Extension") translates text that you select or type on web pages. This Privacy Policy explains which data is processed, where it is sent, and why.

Our Core Promise: The Extension has no servers of its own and collects no analytics or usage data. We do NOT track your browsing history, and we do NOT sell or share your information. Text leaves your browser only when you ask for a translation, and only to the translation service you chose.

1. Text You Translate

Text is sent only when you request a translation: when you click the translate icon or the Translate button, use the right-click menu or the keyboard shortcut (Ctrl+Shift+T / ⌘+Shift+T), or hold Ctrl (⌘ on Mac) over a word with Hover Translate turned on. Depending on the engine selected in the settings, the text is sent over HTTPS to:

  • Google Translate (free engine, default): translate.googleapis.com. If that endpoint is rate-limited or unreachable, the request is retried at Google's second translation endpoint, clients5.google.com.
  • Google Gemini API: generativelanguage.googleapis.com, only if you have entered your own API key. With a key saved, Gemini is also used as a last-resort backup if both Google Translate endpoints fail. Pressing "Test" in the settings sends one request to this service to check your key.
  • Chrome's on-device translator (optional, experimental): if you choose this engine and your browser supports it, translation happens on your computer and the text is not sent anywhere. If it is not available, the Extension falls back to Google Translate.

The "Listen" buttons use your browser's built-in speech synthesis. Translated text is not stored or logged by the developer.

2. No Analytics or Usage Data

Version 1.9.0 contains no analytics. The Extension does not send usage statistics, event counts, installation IDs, crash reports, browsing history, URLs or any tracking data to the developer or to any third party. When it is installed or updated, the Extension deletes the data left behind by the analytics used in older versions: their random client ID and on/off setting, from both local and synced Chrome storage.

3. Data Stored on Your Device

The following is stored locally on your device using Chrome's extension storage (chrome.storage.local). It is never sent to the developer:

  • Your settings: target and source language, translation engine, theme, hover-translate and translate-icon switches, and per-site on/off switches.
  • Window preferences: popup size, dock side and width, and the floating button position.
  • Your Gemini API key, if you add one.
  • A count of successful translations, the install date and your answer to the optional "Rate SmartTranslate" prompt. These are used only to decide whether to show that prompt.

You can remove all of this at any time by removing the Extension. The API key can also be removed with the "Remove" button in the settings.

4. Your Gemini API Key

Your API key stays in your browser's local extension storage. It is sent only to Google's Gemini API, in the x-goog-api-key request header (never in the URL), to authenticate your own requests. The developer never receives it.

5. Permissions Disclosure

To work, the Extension requests the following permissions:

  • storage: to save your settings and optional API key locally.
  • contextMenus: to add the "Translate selection with SmartTranslate" right-click item.
  • activeTab & scripting: when you use the toolbar button, context menu or shortcut, to open the translator in the current tab. This includes tabs that were already open before the Extension was installed. Only the Extension's own bundled scripts are used; no remote code is loaded.
  • Host access to translate.googleapis.com, clients5.google.com and generativelanguage.googleapis.com: to send your translation requests from the Extension's background service worker.
  • Content script on all websites: to show the translate icon and popup next to the text you select, including inside iframes. Page content is not read or sent unless you ask for a translation.

6. Third-Party Services

Text you choose to translate is processed by Google (Google Translate or the Gemini API), and Google's privacy policy applies to it:

  • Google Privacy Policy: https://policies.google.com/privacy

7. Security

All requests use HTTPS and are sent from the Extension's background service worker, not from the web page. Translations are shown as plain text, never as HTML. The user interface is isolated from the page in Shadow DOM.

8. Changes to This Policy

If this policy changes, the effective date above will be updated and the new version published on this page.

9. Contact

If you have any questions about this Privacy Policy, please contact the developer via the official extension support channel on the Chrome Web Store.
